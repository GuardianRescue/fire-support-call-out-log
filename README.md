# Fire Support Call Out Log

Guardian Rescue call-out log: call-out, on scene, departing, back at base and available times,
each with a stamped KM and dashboard photo, GPS position and OB number; signed PDF per call;
weekly and month-end reports.

- Hosted on GitHub Pages (this repository).
- Database and login: Firebase project `fire-support-call-out-log` (Firestore, Johannesburg).
- Records can be added but a signed call cannot be changed or deleted (see the database rules).
- POPIA: privacy notice shown at sign-up; each user reads only their own records.
